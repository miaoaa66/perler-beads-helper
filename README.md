# Perler Beads Helper

A web-based tool for designing and creating Perler bead patterns.

## Features

- Intuitive design interface for creating Perler bead artwork
- Real-time preview with row/column highlighting
- Color selection and position tracking
- Zoom controls for detailed work

## Quick Start

Simply open `index.html` in your web browser:

```bash
# If you have Python installed
python -m http.server 8000
# Then visit http://localhost:8000
```

Or double-click `index.html` to open directly in your browser.

## Usage

1. **Select colors** from the control panel
2. **Click on the canvas** to place beads at positions
3. **Hover** to see row/column highlights
4. **Use zoom** controls for precision work
